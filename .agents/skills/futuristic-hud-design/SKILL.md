# Futuristic HUD Design Skill

Use this skill when building or styling UI components, Canvas animations, or 3D viewports for the J.A.R.V.I.S HUD.

## 1. Stark Aesthetic Palette
- **Obsidian Dark Background**: `#050811` with semi-transparent backdrop blur (`rgba(5, 8, 17, 0.75)` with `backdrop-filter: blur(12px)`).
- **Stark Arc Cyan**: `#00f0ff` (primary glow, borders, text highlights).
- **Amber Gold Alert**: `#ffb703` (warning, pending confirmations).
- **Crimson Lock**: `#ff3366` (critical risk alert).
- **Electric Blue**: `#0077b6` (secondary telemetry).

## 2. 3D Arc Reactor Principles
- Concentric segmented rings rotating with subtle velocity variations.
- Audio volume drives orbital particle pulsation and ring rotation speed.
- Add subtle hexagonal grid or reticle lines on panel borders.
- Keep typography crisp: monospace for code/metrics (`JetBrains Mono`), angular sans for telemetry headers (`Rajdhani`).
